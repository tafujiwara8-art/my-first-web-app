# P1 手動検証チェックリスト

- 対象: ClipFlow P1（マスキング MVP）
- 発行物: GitHub Actions の成果物 `ClipFlow-win-x64`（自己完結 x64）の `ClipFlow.exe`
- 記入方法: 「結果」に **合格 / 不合格 / 保留**、「実施日・実施者」「メモ」に環境（Windows のビルド番号、モニター構成、DPI）と観察結果を書く。

> **実施状況について**: このチェックリストは Linux のコンテナ上で作成した。コンテナでは Windows のアプリを実行できないため、**全項目が未実施**である。自動化できる部分（クリップボード形式の付与、DPI 換算、PNG チャンク、JPEG の黒塗り偏差など）は自動テストで確認済み（`dotnet test`、CI の windows-latest）。ただし、それは実機での見え方・挙動の確認の代わりにはならない。
