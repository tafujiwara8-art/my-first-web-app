# ADR-004: 数式のみ貼り付け（XL-03）は P3 で専用設計する

- 状態: 未決・要検証
- 日付: 2026-10-18

## Context

Excel のセル範囲をコピーし、値ではなく数式だけを別の場所へ貼り付けたいという要件（XL-03）がある。クリップボードの文字列が `=` で始まるかどうかで数式を判定する単純な方法では、次の点を再現できない。

- **相対参照の調整**: Excel で貼り付けると、貼り付け先の位置に応じて `A1` 形式の参照がずれる。テキストの数式をそのまま貼るとこれが起きない。
- **配列数式・構造化参照・他シート参照**などの扱い。
- `=` で始まる文字列データ（数式ではない値）を数式と誤判定する。

候補となる情報源・手段:

1. Excel がクリップボードに置く **`XML Spreadsheet`** 形式。数式が R1C1 の相対形式（`ss:Formula="=R[-1]C+1"`）で含まれ、貼り付け先で相対参照を再構成できる可能性がある。
2. **`Biff12`**（Excel 2007 以降のバイナリ）形式。情報量は多いが、解析コストが高い。
3. Excel デスクトップ版への **COM 経由 `Range.PasteSpecial(xlPasteFormulas)`**。Excel 自身に処理させるため正確だが、Excel が起動していること・COM の権限・プロセス間の安定性に依存する。
4. **Google スプレッドシート**はクリップボード形式が異なる（HTML 中心）。対応範囲を別途定める必要がある。

## Decision

- P1 では実装しない。P0/P1 の構造で考慮するのは、`IClipboardService` に読み取り（`Read`）とクリップボード監視イベントを後から追加できる形にしておくことだけ。
- P3 着手時に、上記 1〜4 を実機の Excel / Google スプレッドシートで検証してから方式を決める。

## Consequences

- 決めるまで XL-03 は提供しない。
- 検証すべき事項（P3 着手前の判断材料）:
  - `XML Spreadsheet` 形式が、対象の Excel バージョン（Microsoft 365 / 2021 / 2019）で常に出力されるか。
  - R1C1 から貼り付け先 A1 への変換の正確さ（絶対参照・混合参照・名前付き範囲・テーブル参照）。
  - COM 方式を採る場合、ネットワーク通信なし・端末内完結の原則と、Excel プロセスへの依存をどう両立するか。
  - Google スプレッドシートを対象に含めるかどうか。
