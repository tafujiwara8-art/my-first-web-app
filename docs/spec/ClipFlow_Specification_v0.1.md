# ClipFlow 機能・基本設計仕様書

- 文書版数：v0.1（構想・要件整理版）
- 作成日：2026-10-18
- 対象：Windowsデスクトップアプリ「ClipFlow」（仮称）
- 状態：要件整理。実装・実機検証・競合調査は未完了

> **文書の読み方**：**採用**は製品への搭載方針が合意された機能を示す。**設計案**は操作・技術方式の推奨であり未確定。**保留**は採用判断または実装時期を先送りしたもの。採用と初期版実装は同義ではない。

## 1. 製品概要

### 1.1 コンセプト

**見せたい情報だけ、瞬時に共有。**

画面をマウスで囲んでキャプチャし、個人情報などをマスキングして、そのままコピー・貼り付けできる、プライバシー重視のWindows常駐ユーティリティ。コピー履歴、OCR、QRコード、表データ処理、ブラウザ連携を統合する。

### 1.2 製品方針（採用）

- マスキングを最大の訴求ポイントとする。
- 外部サービスのAPIを使用しない。AIによる生成・要約・校正・翻訳・自動検出は搭載しない。
- 基本処理は端末内で完結させる。Windows OSのローカルAPIは利用可能。
- 機密情報の扱い、履歴保存制御、元画像の非保存を重視する。
- マウス中心の少ない操作数で、取得→加工→貼り付けを完結させる。
- Windows 11を優先対象とする（対応ビルドの下限は未確定）。

### 1.3 主な想定ユーザー

事務・経理・総務担当者、ITサポート担当者、Web制作・SNS運用担当者、日常的にブラウザ・Excel・Googleスプレッドシートを使用するユーザー。

## 2. 機能要件

### 2.1 マスキング・プライバシー（最優先／採用）

| ID | 機能 | 要件 |
|---|---|---|
| PR-01 | 範囲キャプチャ | マウスの矩形選択で画面の任意領域を取得する |
| PR-02 | 黒塗りマスク | 不透明な色で指定領域の画素を置換する |
| PR-03 | モザイク | 指定領域にモザイクを適用する。秘匿性保証の手段として扱わない |
| PR-04 | ぼかし | 指定領域をぼかす。秘匿性保証の手段として扱わない |
| PR-05 | 複数領域指定 | 一つの画像に複数のマスクを連続指定する |
| PR-06 | マスク調整 | 確定前に範囲・位置・サイズを修正する |
| PR-07 | 加工済み画像出力 | マスクを画像に焼き込み、コピー・貼り付け・保存する |
| PR-08 | 元画像非保存 | プライバシーモード時は元画像を履歴・通常ファイルに保存しない |
| PR-09 | シークレットモード | 履歴収集を停止し、ClipFlow側の永続保存を抑止する |
| PR-10 | 履歴保存除外 | アプリ単位の除外、保持期間・件数・容量の制限、履歴削除を提供する |
| PR-11 | 出力前確認 | マスクの位置ずれ・隠し忘れを目視確認できる |

**安全要件**：黒塗り等の完全不透明な画素置換を機密情報の秘匿に推奨する。ぼかし・モザイクは推測・復元リスクがあり、同等の安全性を主張しない。加工済み画像に元画素・編集レイヤー・不要なメタデータが残らないことを検証する。クリップボードや貼り付け先アプリ、OSの履歴・一時領域はClipFlowだけで完全制御できないため、「完全に痕跡が残らない」とは表現しない。

### 2.2 クリップボード・貼り付け（採用）

| ID | 機能 | 要件 |
|---|---|---|
| CB-01 | コピー履歴 | テキスト、URL、画像、書式付きデータ等を監視・一覧化する |
| CB-02 | 履歴検索・編集 | 検索、編集、削除、固定、プレビューを行う |
| CB-03 | 直接貼り付け | 直前の入力先へ可能な範囲で貼り付ける |
| CB-04 | 形式選択 | テキストのみ、元書式維持、HTML、画像、ファイル等の対応形式を選択する |
| CB-05 | 複数履歴一括貼り付け | 複数履歴を選び、順序・区切りを指定してまとめて貼り付ける |
| CB-06 | 連続コピー | 複数のコピーを順番に収集する |
| CB-07 | 定型文・スニペット | 登録、分類、検索、編集、即時貼り付けを行う |
| CB-08 | 自動分類 | URL、メールアドレス、文章、画像、表などをローカルのルールで分類する |
| CB-09 | 重複履歴統合 | 同一内容の履歴を統合し、重複保存を抑える |
| CB-10 | URL・メール抽出 | テキスト中のURLとメールアドレスを抽出し一覧化する |
| CB-11 | テキスト整形 | 不要な空白・改行除去、全角半角等の基本変換を行う |

**留意点**：複数形式を保持できる場合は元のクリップボード形式を関連付けて保存する。元データにない書式は復元できない。直接貼り付けはフォーカス復元、権限差、アプリ固有挙動を検証する。ファイル貼り付けやHTML形式は対応先を明示する。重複判定では書式・画像・コピー元の差異を失わない設計を検討する。

### 2.3 範囲選択・OCR・QRコード（採用）

| ID | 機能 | 要件 |
|---|---|---|
| SC-01 | 共通矩形選択 | 画面上の領域をマウスで囲む共通UIを提供する |
| SC-02 | OCR | 選択領域の文字を端末内で認識し、編集・コピー・履歴保存する |
| SC-03 | OCR結果整形 | 誤認識修正、改行・空白補正を可能にする |
| SC-04 | 画像切り取り | OCRと別に、選択領域を画像そのものとしてコピー・保存する |
| SC-05 | QR読み取り | 選択領域のQRコードをローカル解析する |
| SC-06 | QRからURLを開く | URLを表示・確認後、既定ブラウザで開く |
| SC-07 | QR生成 | URL・文字列からQRコード画像をローカル生成する |
| SC-08 | 後処理切り替え | 取得済みの画像にOCR、QR解析、マスキング等を追加適用する |

OCRはWindowsのローカル文字認識機能を想定。認識精度は言語パック・画質・レイアウトに依存する。QRのURLを無条件に自動起動しない（誤誘導対策）。

### 2.4 Excel・スプレッドシート（採用）

| ID | 機能 | 要件 |
|---|---|---|
| XL-01 | 表形式維持 | 行・列を保持してコピー・貼り付けする |
| XL-02 | 表の転置 | 行列を入れ替える |
| XL-03 | 数式のみ貼り付け | 対応アプリで数式を優先して貼り付ける |
| XL-04 | 値のみ貼り付け | 数式・書式を除いた値を貼り付ける |
| XL-05 | 空白削除 | 空白行・空白列・文字間の不要な空白を削除する |
| XL-06 | 画像から表抽出 | OCRで表の文字と行列構造を抽出し、編集・貼り付けする |

**実装制約**：Excelデスクトップ版とGoogleスプレッドシートでは数式・書式・貼り付け形式が異なる。数式のみ貼り付けは対象アプリごとの仕様確認が必要。画像の表抽出は複雑な罫線・結合セル・欠損セルを正確に復元できる保証はなく、確認画面を設ける。

### 2.5 ブラウザ・Web（採用）

| ID | 機能 | 要件 |
|---|---|---|
| WB-01 | ページタイトル＋URL取得 | 現在のページのタイトルとURLを取得する |
| WB-02 | ページ内リンク一覧 | ページ内のリンクを抽出・一覧化する |
| WB-03 | 選択文字列のWeb検索 | コピーまたはOCRした文字列で既定の検索エンジンを開く |
| WB-04 | 追跡パラメータ除去 | URLから既知の追跡用クエリパラメータを削除する |
| WB-05 | Web画像の個別保存 | ページ内画像を選択して保存する |

**実装案**：Chrome/Edgeのブラウザ拡張とローカルアプリの連携を検討。これは外部サービスAPIではない。Web検索・URL起動はブラウザでインターネットにアクセスするが、ClipFlow自身のクラウド処理ではない。サイト権限、動的ページ、保護画像、認証領域、利用規約を考慮する。追跡パラメータ削除は機能上必要なクエリを誤削除しないようプレビューと元URLへの復帰を用意する。

### 2.6 画像・スクリーンショット（採用）

| ID | 機能 | 要件 |
|---|---|---|
| IM-01 | 範囲・全画面・ウィンドウ撮影 | 画像を取得する |
| IM-02 | スクロール撮影 | 長いページを連結して画像化する |
| IM-03 | 画像サイズ変更 | 幅・高さ・縦横比を変更する |
| IM-04 | カラーピッカー | 画面上の色をHEX/RGBで取得する |
| IM-05 | 注釈 | 矢印・文字・矩形等を描画する |
| IM-06 | 画像コピー・保存 | PNGを基本とし、JPEGも選択可能にする |
| IM-07 | 画像履歴・プレビュー | サムネイルと元データを管理する（シークレット時を除く） |

スクロール撮影はページ構造・固定ヘッダー・動的描画等により失敗する場合がある。初期の対応範囲はブラウザ別に定める。

## 3. 起動・操作UI

### 3.1 採用した操作コンセプト

- Windows常駐、タスクトレイから起動可能。
- 画面端にマウスカーソルを接触させると起動フック（小さなタブ）が現れる。
- 小型のフローティングバッジを表示し、通常クリックで履歴パネルを開く。
- バッジの長押しと上下左右への移動で機能を選択する。
- 機能選択後に共通の矩形範囲選択へ移行する。
- ショートカットキーでも主要機能を直接起動できる。
- バッジの最前面表示・自動非表示・位置変更を設定可能にする。

### 3.2 初期割当（設計案）

| 操作 | 動作 |
|---|---|
| バッジを通常クリック | 履歴パネル |
| 長押し＋上 | OCR |
| 長押し＋右 | 翻訳ではなく、再割当が必要（翻訳は非搭載） |
| 長押し＋左 | スクリーンショット／マスキング |
| 長押し＋下 | QRコード |

**未確定**：右方向の正式割当、マスキング専用ジェスチャー、長押し判定時間、移動距離、解除条件。初期値300ms程度は提案値であり未承認。通常の左クリック長押しを画面全体で横取りしない。バッジ上の操作に限定することを推奨。

### 3.3 Desktop Frame（Smart Frame）との共存

- 既存デスクトップ整理アプリにも画面端起動構想があり、検知領域・最前面制御・常駐処理が競合する可能性がある。
- **設計案**：右上／右下等の領域分離、位置設定、必要に応じた相互抑制。
- **未検証**：既存ソースの実装、フック方式、ホットキー、複数モニター動作。実コードを確認してから共通化の要否を判断する。

## 4. 代表的な操作フロー

### 4.1 マスキング

1. 画面端フック／ショートカットからキャプチャ開始。
2. マウスで矩形選択して画面を取得。
3. マスキングモードを選び、隠す箇所を複数指定。
4. 黒塗り等を適用し、加工後画像をプレビュー。
5. 元画素を残さない形式に確定し、コピー・貼り付け・保存。
6. シークレットモードではClipFlowの履歴に元画像・加工画像を保存しない。

### 4.2 複数履歴の一括貼り付け

1. 連続コピーで履歴を蓄積。
2. 履歴パネルで複数項目を選択。
3. 順序、区切り、貼り付け形式を指定。
4. プレビュー後、元の入力先へ貼り付ける。

### 4.3 OCR／表抽出

1. 画面を矩形選択。
2. OCRまたは表抽出を選択。
3. 認識結果を確認・修正。
4. テキストまたは表形式でコピー・貼り付け。

### 4.4 QRコード

1. QRモードで矩形選択。
2. ローカル解析して結果を表示。
3. URLの場合は確認してブラウザで開く。URL以外はテキストとして扱う。

## 6. 非機能要件・セキュリティ

1. **プライバシー優先**：履歴収集を一時停止でき、機密アプリを除外できること。
2. **画像の不可逆加工**：安全な黒塗りでは、マスク対象画素を実データ上で置換すること。
3. **外部API不使用**：処理内容を外部のAI・OCR・翻訳APIに送らないこと。
4. **ローカル動作**：コピー、撮影、OCR、QR解析、マスキングはオフラインで実行できること。
5. **権限と安全性**：管理者権限アプリ、保護画面、ブラウザの権限制限に従うこと。
6. **低負荷**：常駐時のCPU・メモリ・ディスク使用量を測定し、上限を設計すること。
7. **マルチモニター**：座標、DPI、画面端検知、範囲撮影を検証すること。
8. **障害時の保護**：異常終了時に機密の一時画像や履歴が不必要に残らない設計を検討すること。
9. **データ保持**：保存期間、件数、容量、削除手段、エクスポート可否を仕様化すること。
10. **アクセシビリティ**：マウス以外のショートカット操作、キーボードフォーカスを考慮すること。

## 7. 非搭載・保留

### 7.1 非搭載（方針確定）

- AI文章生成、要約、校正、言い換え
- AIによる個人情報の自動検出
- クラウド翻訳、オンラインOCR、外部API連携
- オフラインAI翻訳
- Markdown変換・Markdown形式コピー
- クラウドへの履歴同期

※ 翻訳は当初の構想にあったが、AI・外部API不使用方針により現段階では搭載対象外。

### 7.2 保留または今回未採用

- アプリ別ジェスチャー設定、ホイール履歴切り替え、ドラッグ＆ドロップ貼り付け等の追加マウス操作
- 固定マスクテンプレート
- 画面上の寸法測定
- Webページ全文保存
- 表の重複行削除、汎用CSV/TSV変換等、今回明示的に採用されなかった表加工機能

## 10. 検証計画（初期案）

- マスク画像をPNG/JPEGへ出力し、指定領域に元画素が存在しないことを検査する。
- シークレットモードでClipFlowの履歴DB・キャッシュ・一時ファイルに意図しない保存がないか確認する。
- Word、メモ帳、Excel、Googleスプレッドシート、Chrome、Edgeでコピー・貼り付け互換性を検証する。
- 日本語・英語のOCR、低解像度画像、複雑な表、複数QRコードで精度と失敗時の挙動を確認する。
- マルチモニター、DPI倍率変更、最前面ウィンドウ、管理者権限アプリ、保護画面で動作確認する。
- Desktop Frameと同時起動し、画面端フック・ジェスチャー・常駐処理の競合を確認する。
